title: 4e. Multiple Reference Timeline
---

Use the multiple reference timeline feature to let different classes access the same questions according to their specific schedules.

1.  Enable the **Multiple Reference Timeline** feature.

    ![4E-1](/img/instructors/4E-1.png)

    <span style={{ color: 'red' }}>If you don’t see the Multiple Reference Timeline on your Components page, it means the feature isn’t enabled. Contact your instance admin to enable it.</span>

2.  Create a new timeline for each class.

    ![4E-2](/img/instructors/4E-2.gif)

3.  The **Default Timeline** will follow the settings on the main assessment page.

    ![4E-3](/img/instructors/4E-3.png)

4.  If a class needs to deviate from the default timeline setting, click on the date of the assessment release to set a new timeline.

    ![4E-4](/img/instructors/4E-4.gif)

    In this example, Class A will follow default timeline (i.e. 12th Sep), while Class B will have its own timeline (i.e. 14 Sep) for Lab 1.

5.  Finally, assign relevant students to desired timeline. You may do this under **Manage Users** page.

    ![4E-5](/img/instructors/4E-5.gif)

Assigned classes will see the assessment only according to their assigned timeline. If you edit the questions in the assessment, you only need to do it once!
