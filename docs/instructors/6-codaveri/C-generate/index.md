title: 6c. Problem Generation using Codaveri
---

You may use Codaveri to help generate programming questions!

1. Go to the Assessment page and click **Generate Programming Question**

2. Type in a prompt.

3. Select the programming language and click **Generate**.

   The AI will generate a sample question, with other relevant settings such as solution code, test cases etc.

   ![6C-1](/img/instructors/6C-1.gif)

4. If you are NOT satisfied with the question generated, you may make relevant edits accordingly, or re-generate a question.

5. If you are satisfied with the question generated, you can export the question by clicking **Export** button.

6. A popup will be shown. Choose the questions you wish to export and click **Export**.

7. When done, refresh the assessment page. You will see the questions being exported.

   ![6C-2](/img/instructors/6C-2.gif)
