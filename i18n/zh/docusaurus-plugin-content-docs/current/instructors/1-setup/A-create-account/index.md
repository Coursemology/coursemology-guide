要注册为用户：
点击 创建账户。
输入您的账户信息。
点击 注册。
您应该会看到一条通知，告知您一封确认邮件已发送到您的邮箱。

![1A-1](/img/instructors/1A-1.gif)

确认您的账户：
登录您的邮箱
点击邮件中的确认链接

![1A-2](/img/instructors/1A-2.gif)

然后您即可继续登录。
