:::info

新注册用户默认设置为学生

:::

登录 Coursemology。

![1B-1](/img/instructors/1B-1.gif)

要更新您的账户设置：
  * 点击页面右上角的个人资料图片。
  * 从下拉菜单中选择 **账户设置**。
  * 然后您可以更新您的显示名称、上传个人资料图片或更改密码。

![1B-2](/img/instructors/1B-2.gif)

请注意，作为学生，您无法创建课程！  
（您需要成为讲师。您可以通过点击 **申请成为讲师** 按钮来申请。）

![1B-3](/img/instructors/1B-3.png)
